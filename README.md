# 小骑士的探险 🛡️

一款致敬《以撒的结合》核心玩法的俯视角肉鸽地牢网页游戏（纯 Canvas 像素美术，零第三方依赖）。
你扮演一位在黑暗地牢中探险的**小骑士**，用圣泪（子弹）清空房间、寻找道具、击败每层的 Boss，一路下到第三层击败深渊大骑士，夺回被封印的圣辉。

## 运行方式

需要 Node.js 18+。在项目根目录执行：

```bash
node server.js
```

然后打开浏览器访问 **http://127.0.0.1:8123/**

> 请不要直接双击 index.html（file:// 下部分浏览器无法加载自定义背景音乐）。

## 操作方式

| 输入 | 作用 |
| WASD | 移动 |
| J / K | 骨钉挥击：斩出青白光刃（高伤害、可穿透敌人，带前冲） 
| E / 空格 | 互动（开启宝箱、使用楼梯等） |
| P / Esc | 暂停 |
| Tab / M | 打开楼层地图（已探索房间 + 门连线 + Boss/宝箱/楼梯标记，带迷雾） |
| 移动端 | 左手方向区移动（整区可按/滑动换向/斜向）；右手大号「斩」键攻击（点按即斩、自动瞄准最近敌人）；右上「地图」 |

## 核心玩法（以撒式）

- **随机地牢**：每层随机生成 5–8 个房间 + 1 个 Boss 房（泥土地牢 → 幽暗墓窟 → 炼狱深渊），四向门连通；清空房间的敌人后门锁打开，进入下一房间。
- **战斗**：普通/宝藏房间会刷出敌人（飞行怪、吐弹怪、史莱姆会分裂、骷髅兵会蓄力冲锋、火焰小鬼环绕射击…），击败 Boss 掉落道具并出现通向下一层的楼梯。
- **道具系统**：击杀敌人或开启宝箱会随机掉落道具（含属性道具与外观道具），改变你的圣泪形态（三连/贯穿/追踪/分裂/灼烧/镭射…）、属性（伤害/射速/移速/射程/红心）甚至角色外观（王冠、光环、护目镜、恶魔角、圣翼、披风等会以悬浮标记+光晕显示在角色身上）。
- **属性与心**：红心容器（血上限）与半心伤害；受伤后短暂无敌并硬直。
- **完整流程**：开始界面 → 三层地牢 → 通关界面；死亡界面显示本次探索统计（击杀数、拾取道具数、存活时间、抵达层数、清空房间、发射圣泪）。
- **骨钉斩击**：按 `J`/`K`（手机「斩」键）挥动骨钉，向前斩出青白光刃——伤害约为圣泪的 1.8 倍、可穿透多个敌人，并让角色向前小幅突进，是清怪与打断敌人的好手段。
- **楼层地图**：按 `Tab`/`M`（手机用「地图」按钮）查看本层已探索的房间、门连接与 Boss/宝箱/楼梯标记，未探索区域保持迷雾。
- 内置占位 BGM（WebAudio 程序化原创小调，随楼层/Boss 切换氛围）。

## 技术结构（零依赖，原生 ES Modules + Canvas 2D）
```
index.html                入口
css/style.css             像素风 UI 样式
js/
  config.js               全局数值/主题配置
  util.js                 数学/像素精灵/碰撞
  art/                    硬像素光栅器 + 手绘帧(角色/怪物/Boss/物品/世界)
  items.js                道具目录与效果
  input.js                键盘 + 触屏虚拟输入
  audio.js                WebAudio 音效 + 程序化BGM + 自定义音乐加载
  entities/               玩家/敌人/Boss 实体与 AI
  engine/                 地牢生成/房间/弹体/粒子/主引擎
  ui/hud.js               DOM HUD(红心/道具/层数/Boss血条)
  main.js                 启动/主循环/界面/移动端控制
server.js                 零依赖静态服务器
tools/                    headless Edge + CDP 自动化验证/截图(需要本地安装 Edge)
shots/                    自动化试玩截图(供人眼复核画面)
```
## 已知说明

- 主角为原创角色设定（小骑士），视觉采用黑色粗描边+高饱和低多边形像素风致敬以撒，但素材全部为代码现绘，无任何原作素材。
- 移动端控制：左手方向区移动 + 右手「斩」键（已简化为两键操作，攻击自动瞄准最近敌人）.
- 数值/难度/道具池可集中在 `js/config.js`、`js/items.js` 调整。
