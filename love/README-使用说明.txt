小站使用说明（给朱景澈看）
=========================

这个文件夹就是「给江鑫颖的小站」的网页文件，发布后手机打开链接即可。

一、怎么改在一起的日子（重要）
  打开 index.html，找到这一行（大约在文件末尾的 <script> 里）：

      const START = new Date(2026, 7, 30);   // 月份从 0 开始：7 = 8 月

  解释：2026, 7, 30 = 2026 年 8 月 30 日，这一天算「第 1 天」。
  改成你们真正的纪念日即可，天数会自动计算、每天零点自动 +1，不用再改。

二、怎么放合照
  把图片命名为 photo.jpg，放在本文件夹（和 index.html 同一层），
  页面里的「我们的照片」就会自动显示。

三、她怎么打开最方便
  1) 你把链接发给她（微信/短信都行），她点一下就能看；
  2) 想更像 App：iPhone 用 Safari 打开 → 分享 → 添加到主屏幕；
     安卓用 Chrome/夸克打开 → 右上角菜单 → 添加到主屏幕。
     加完后桌面会出现粉色爱心图标，点一下就能打开。
  3) 页面支持离线缓存：她打开过一次之后，没网也能看。

四、文件说明
  index.html              页面本体（含全部样式/脚本，可单独打开）
  manifest.webmanifest    "添加到主屏幕"用的配置
  sw.js                   离线缓存
  icon-192/512.png        安卓图标
  apple-touch-icon.png    苹果图标
  photo.jpg               你的合照（需要自己放）
